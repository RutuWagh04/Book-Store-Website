# 📚 Online Book Store Website

## Introduction

The **Online Book Store Website** is a web-based platform designed to simplify the process of browsing, purchasing, and managing books online. It provides a seamless shopping experience for customers while enabling administrators to efficiently manage books, orders, and users. The system connects readers, sellers, and administrators through a user-friendly and responsive interface.

---

## Key Features

### Admin Module

* Book Management (Add, Update, Delete Books)
* Category & Inventory Management
* Order & Sales Tracking
* User Management (Customers)
* Feedback & Review Monitoring
* Reports & Analytics Generation

---

### User (Customer) Module

* User Registration & Login
* Browse Books by Category or Author
* Book Details & Reviews
* Add to Cart & Order Management
* Online Payment / Cash on Delivery Option
* Order History & Wishlist Management

---

### Shopping Cart Module

* Add & Remove Books from Cart
* Quantity Update
* Price Calculation & Checkout
* Secure Order Processing

---

### Review & Feedback Module

* Customer Reviews & Ratings
* Feedback Submission
* Admin Moderation of Reviews

---

## Highlights

* **User-Friendly Interface:** Simple and intuitive design for easy navigation.
* **24×7 Accessibility:** Customers can browse and purchase books anytime, anywhere.
* **Efficient Book Management:** Admins can manage inventory and update book listings in real time.
* **Secure Transactions:** Safe handling of user data and order details.
* **Scalable Architecture:** Designed for future enhancements like payment gateways and recommendations.

---

## Technologies Used

* **Front-End:** HTML, CSS, JavaScript
* **Back-End:** PHP
* **Database:** MySQL
* **Tools:** Visual Studio / VS Code, XAMPP, Google Chrome
